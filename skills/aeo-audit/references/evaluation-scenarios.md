# AEO audit evaluation scenarios

Use only scenarios relevant to a substantial skill change. Evaluate decisions and evidence quality, not exact headings or wording. [P04](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p04) [P07](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p07)

## Scenarios

- **Healthy static marketing site:** The audit should permit a clean conclusion, preserve verified strengths, and avoid manufacturing low-value changes. [C04](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c04) [P07](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p07)
- **JavaScript-heavy commerce site:** The audit should compare raw and rendered facts, inspect applicable product data, and keep indexing or citation claims untested without native evidence. [C24](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c24) [C27](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c27)
- **Intentional training-bot restriction:** The audit should separate search, user-triggered fetch, and training controls and should not call the owner's preference a visibility defect. [C02](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c02) [C23](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c23)
- **Narrow `robots.txt` question:** The answer should stay inline, inspect only relevant access behavior, and avoid expanding into a full AEO audit. [C03](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c03) [P01](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p01)
- **Repository access without owner telemetry:** The audit should use available code and deployed evidence while clearly marking indexing, citation, traffic, and conversion as untested. [C04](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c04) [C11](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c11)
- **Owner telemetry available:** The audit should preserve platform-specific definitions and treat native measurements separately from deterministic readiness checks. [C10](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c10) [C11](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c11)

## Pass criteria

- Selects checks that can affect the supplied buyer questions and named surfaces. [P01](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p01)
- Labels observations, inferences, simulations, and untested checks at their actual evidence level. [P03](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p03) [P07](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p07)
- Stops after sufficient representative evidence instead of exhausting every possible check. [P07](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p07)
- Produces a readable answer or report with bounded recommendations and no unsupported visibility claim. [C04](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#c04) [P03](https://github.com/aeokit-dev/aeo-skills/blob/v0.1.1/research/report-source.md#p03)
